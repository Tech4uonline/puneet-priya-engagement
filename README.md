# Puneet & Priya — Engagement Invitation

A static, mobile-friendly engagement invitation website for the celebration on Friday, 4 December 2026, at The Palace, Kanpur.

## Hosting

This site is published with **GitHub Pages** using the workflow in `.github/workflows/pages.yml`.

After the first deployment, the public site will be available at:

https://tech4uonline.github.io/puneet-priya-engagement/

The invitation uses relative paths for `assets/`, so the HTML, photographs, and music must remain in their current locations.


GitHub Pages is configured to deploy from the GitHub Actions workflow.
